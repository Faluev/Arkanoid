# Арканоид — практическая 2.6

Демонстрация создания, отражения и уничтожения шариков на одной сцене Unreal Engine 5.8.4.

## Запуск

1. Откройте `Arkanoid.uproject` в Unreal Engine 5.8.4. Если редактор предложит собрать модуль, для этого понадобятся Visual Studio 2022 или Build Tools с MSVC v143 и Windows SDK.
2. На стартовой карте `L_BallSimulation` нажмите **Play**. Сцену можно также запустить в режиме **Simulate**.
3. Шарик появляется у спавнера, летит к отражателю, меняет направление и исчезает в зоне уничтожения. Следующий шарик появляется через 3,2 секунды.

## Классы

- `ABall` перемещает шарик по плоскости XY с учётом `DeltaTime`. Проверка столкновения вдоль пути позволяет отразить направление по нормали препятствия.
- `ASpawner` создаёт шарики по позиции и направлению компонента `SpawnDirection`.
- `AMyKillZone` обрабатывает пересечение со своим объёмом и уничтожает шарик.

В **Output Log** по фильтру `Arkanoid Ball` видны создание, отражение и уничтожение каждого шарика.
